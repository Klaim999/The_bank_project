# Виджет по банковским операциям 

Проект, который будет готовить данные для нового виджета на бэкенде. Виджет появится в личном кабинете онлайн-банка.  

## Установка: 

1. Клонируйте репозиторий:
```
git clone git@github.com:Klaim999/The_bank_project.git
```

## Описание и использование:

1. Функции get_mask_card_number и get_mask_account защищают данные пользователей. Например, при вводе номера карты 7000792289606361 мы получаем 7000 79****6361.
2. Функция mask_account_card обрабатывает информацию о картах и счетах. Выводит тип платежной системы и замаскированный счет. Ввод: Visa Classic 6831982476737658, вывод: Visa Classic 6831 98**** 7658. 
3. Функция get_date преобразует формат времени. Она принимает значение 2024-03-11T02:26:18.671407 и возвращает 11.03.2024.
4. Функция filter_by_state выводит отсортированный список по ключу.
5. Функция sort_by_date сортирует дату по заданному параметру.
